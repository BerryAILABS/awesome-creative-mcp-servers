# Contributing to Awesome Creative MCP Servers

Thank you for helping curate the best creative MCP servers!

## Submission Criteria

To maintain quality and trust, all submissions must meet the following standards:

1. **Active & Public:** The repository must be public, have functional installation/setup documentation, and show commit activity within the past 180 days.
2. **MCP Compliant:** The tool must adhere to the standard Model Context Protocol specifications (stdio, SSE, or Streamable HTTP).
3. **Creative Domain Fit:** The server must provide utility in design, brand systems, typography, image generation, video editing, audio synthesis, 3D modeling, or ad creative operations.
4. **Mandatory Disclosure:** If you are the author, maintainer, or affiliated with the project you are adding, you **must explicitly state your affiliation** in your pull request. Undisclosed self-promotion will be closed.

## How to Submit

1. Fork this repository.
2. Add your server to the appropriate category in `README.md` following the existing markdown table format:
   ```markdown
   | [Owner/repo-name](https://github.com/owner/repo-name) | Clear description of capability and primary workflow. | ⭐ Count | YYYY-MM |
   ```
3. Add a corresponding row to `data/servers-2027-11.csv`.
4. Open a Pull Request with a clear title (e.g., `Add ProjectName to Design & UI`).

We review and merge community additions weekly.
